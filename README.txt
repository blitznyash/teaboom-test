# Карточка товара Teaboom

Свёрстанная карточка товара «Ананасовый улун» с интерактивным слайдером, табами и корзиной.

## Технологии
- HTML5
- CSS3
- Vanilla JavaScript (без сторонних библиотек)

## Как запустить локально
1. Скачайте папку с проектом.
2. Откройте файл `index.html` в любом браузере.
3. Готово. Дополнительные сборки или сервер не требуются.

## Структура проекта
- `index.html` — разметка страницы
- `css/style.css` — стили
- `js/script.js` — логика (слайдер, табы, корзина)
- `fonts/` — локальные шрифты
